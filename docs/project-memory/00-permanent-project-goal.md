# Permanent Project Goal

## Mission

Build a premium, free, public SEO audit tool for Nexora Creation.

The product must feel more complete, useful and enjoyable than common free SEO checkers.

The visitor must be able to enter a URL and receive a logical, evidence-based and actionable report without mandatory signup.

## Core Values

| Value                    | Definition                                                                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Accuracy**             | Every finding must be verifiable from the page content or response. No fabricated data. No hallucinated issues.                              |
| **Transparency**         | The user must understand why each finding exists, what evidence supports it, and what to do about it.                                        |
| **Security**             | The public scanner must be hardened against SSRF, DNS rebinding, and resource-exhaustion attacks before any audit engine runs.               |
| **Premium UX**           | The experience must feel polished, fast and respectful — not like a lead-generation trap.                                                    |
| **Real user usefulness** | Reports must prioritize actionable issues over vanity scores.                                                                                |
| **Maintainability**      | Every rule must be independently tested, provenance-tracked, and replaceable.                                                                |
| **Accessibility**        | The product and its reports must be usable with keyboard, screen reader, and reduced motion.                                                 |
| **Performance**          | The quick page audit must complete in seconds. The report must load instantly.                                                               |
| **Search visibility**    | Public reports must be indexable and optimised for organic discovery.                                                                        |
| **Lead generation**      | The free tool must naturally demonstrate Nexora Creation's expertise and invite further engagement — without blocking results behind a form. |

## Non-Goals for Version 1

- Google Search Console integration
- Google Analytics import
- Mandatory user login
- Billing or subscriptions
- Backlink databases
- Keyword-volume databases
- Rank tracking
- Competitor keyword databases
- Automatic Google indexing
- Automatic WordPress modifications
- Fabricated traffic or ranking data
- Unrestricted full-site crawling

## Alignment With Nexora Creation

The SEO audit tool is a public demonstration of Nexora Creation's engineering and design quality. Every interaction — from the URL input to the shareable report — should reinforce trust in Nexora's ability to deliver polished, secure, and genuinely useful software.
